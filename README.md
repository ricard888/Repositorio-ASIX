# 🚀 Mi Repositorio ASIX & Proyectos Personales

¡Hola! 👋 Bienvenido/a a mi repositorio principal. Aquí voy acumulando mi trayectoria, prácticas y proyectos personales mientras me adentro en el mundo de la **Administración de Sistemas Informáticos en Red (ASIX)** y la programación. 

Siempre estoy buscando aprender tecnologías nuevas, entender cómo funcionan las redes e infraestructura desde dentro y automatizar tareas del día a día mediante código.

---

## 🛠️ Tecnologías y Herramientas Utilizadas

A lo largo del repositorio verás proyectos y pruebas construidas con el siguiente conjunto de tecnologías:

* **Lenguajes de Programación y Scripting:**
  * **Python 3:** Desarrollo de bots, automatización de scripts de red y APIs.
  * **PowerShell / Bash:** Automatización y gestión de la administración de sistemas.
* **Desarrollo Web & APIs:**
  * **Flask / REST APIs:** Creación de servidores web ligeros y gestión de peticiones HTTP (`requests`, `Invoke-RestMethod`, `curl`).
* **Bases de Datos:**
  * **SQLite / SQL:** Gestión de persistencia de datos para peticiones y registros locales.
* **Entorno y Herramientas:**
  * **VS Code:** Entorno principal de desarrollo y gestión de intérpretes.
  * **Git & GitHub:** Control de versiones.
  * **Entornos Virtuales de Python (`venv` / `.env`):** Gestión segura de dependencias y variables de entorno.
