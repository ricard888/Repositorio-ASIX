# Formulario Básico con HTML y PHP #

Este es un pequeño proyecto de prueba que he hecho para practicar cómo conectar un formulario de HTML con un script de PHP:

* **Básicamente es una página con un index.php que te pide el nombre. Al darle al botón de enviar, el código recoge ese dato usando el método POST y te muestra un mensaje de bienvenida por pantalla. Para hacerlo funcionar en local he utilizado XAMPP, así que solo hay que meter la carpeta en htdocs, arrancar Apache y abrirlo desde el navegador en localhost.
