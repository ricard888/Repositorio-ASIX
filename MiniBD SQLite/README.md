# Mini Base de Datos con SQLite

Este es un proyecto pequeño sobre gestion de base de datos combinando
**Python** con **SQLite**. Es ideal para aprender a almacenar, crear y
leer datos en una cantidad pequeña de forma local.

## Caracteristicas

- Creacion de la BD
- Estructura de tabla con clave autoincremental
- Insercion + Consulta de los datos

## Requisitos tecnicos

- **Python Version 3.X** ( Viene instalado con el sistema )
- **Sqlite3** ( Viene instalado con el sistema )
